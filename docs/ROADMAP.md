# 12 周交付路线图

## 第 0 周：项目治理

- 创建 GitHub 远端仓库。
- 固化 `AGENT.md` 开发流程。
- 建立 README、基础目录和项目文档。
- 明确提交规范、敏感信息规则和 LoongArch 适配原则。

## 第 1-2 周：基础架构与兼容性前置

- 初始化 Vue 3 前端和 NestJS 后端工作区。
- 建立环境变量模板、健康检查接口和基础配置。
- 设计用户、角色、课程、班级、实训任务、评价模板等核心数据模型。
- 形成 LoongArch + 银河麒麟依赖风险清单。

## 第 3-4 周：上传与解析闭环

- 完成学生提交、文件上传、对象存储、解析任务状态流。（已完成后端链路和前端基础上传入口）
- 支持 Word、PDF、截图和代码包的基础解析。
- 建立可重复测试样例和解析回归用例。

## 第 5-6 周：规则核查与 LLM 初评

- 实现确定性规则核查。（已完成基础需求覆盖、步骤完整性、证据质量与风险文本识别）
- 接入统一 LLM Gateway。（已完成基础 OpenAI-compatible HTTP 网关）
- 实现脱敏摘要、JSON Schema 校验、失败重试和待人工复核状态。（已完成脱敏摘要、JSON 结构校验、评价 worker 和未配置 LLM 降级草稿）

## 第 7-8 周：教师复核与评价管理

- 支持教师逐项改分、评语、最终确认。（已完成后端复核、发布和学生已发布反馈接口；前端已完成逐项教师分、指标评语、总评保存、发布与初评查看入口）
- 支持课程、班级、实训任务筛选与任务选择。（已完成前端基础选择器和报表筛选入口）
- 支持评价模板版本化，避免历史成绩被新规则覆盖。（已完成后端模板版本字段和前端默认模板创建入口）
- 支持基础数据维护。（已完成前端课程、班级、课程-班级绑定、默认评价模板、实训任务创建入口）
- 支持学生查看已发布反馈。（已完成后端接口和前端基础查看入口，待独立学生端页面）

## 第 9 周：报表与导出

- 生成学生个人报告、班级/课程统计报表。（已完成后端已发布评价统计基础）
- 支持 Excel/PDF 异步导出。（已完成 `export_report` worker、最小 `.xlsx`/`.pdf` 生成和对象存储落盘）
- PC Web 展示统计概览与导出任务状态。（已完成基础入口和成功导出下载，待筛选和图表增强）
- 验证中文字体、图表嵌入和目标平台导出能力。

## 第 10 周：目标环境部署验证

- 在 LoongArch + 银河麒麟高级服务器版完成完整部署演练。
- 输出 systemd 配置、容器方案和冒烟测试记录。

## 第 11 周：安全、性能与稳定性

- 完成越权测试、上传安全、Zip Slip 防护、Prompt Injection 防护。
- 使用 50-200 份样例提交完成批量试跑。
- 建立性能基线和失败任务治理策略。

## 第 12 周：验收交付

- 准备演示数据、用户手册、部署手册、开发手册。
- 形成验收包、演示脚本和最终版本 tag。
