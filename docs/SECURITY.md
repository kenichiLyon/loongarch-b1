# 安全与合规基线

## 数据安全

- 学生姓名、学号、联系方式等敏感信息不得默认发送给云端大模型。
- LLM 调用只发送脱敏摘要、必要证据片段和评分上下文。
- API Key、Token、数据库密码必须通过环境变量或安全配置注入，不得提交仓库。

## 身份认证与权限

- 首个管理员只能通过 `AUTH_BOOTSTRAP_TOKEN` 在空库状态初始化，创建后不得重复使用。
- 密码使用 Node.js `scrypt` 哈希保存，不在数据库或日志中保存明文密码。
- 管理接口默认要求 Bearer Token；管理员负责用户创建，管理员/教师负责课程、班级、任务和评价模板维护。
- `AUTH_TOKEN_SECRET` 生产环境必须使用高强度随机值，并与 `AUTH_BOOTSTRAP_TOKEN` 分开轮换。

## 上传安全

- 限制文件大小、数量、扩展名和 MIME 类型。
- 单文件大小由 `UPLOAD_MAX_BYTES` 控制，文件名在写入对象存储前会去除路径与危险字符。
- 文件保存到 `STORAGE_ROOT` 下的 artifact 前缀目录，解析任务通过 `jobs` 表排队，后续 worker 再处理原始文件。
- 上传请求不直接执行解析，避免高并发下长请求占用 API worker；解析 worker 按批领取任务并限制单次文本提取长度。
- 对压缩包执行路径穿越、Zip Slip、超大解压和嵌套深度检测。
- 不自动执行学生代码，首版仅做静态扫描。

## 评分安全

- 上传内容不得覆盖系统评分规则。
- LLM 输出必须通过 JSON Schema 校验。
- 教师改分、最终确认、结果发布必须记录审计日志。

## 报表安全

- 报表导出需记录操作者、筛选条件、生成时间和文件 hash。
- 学生只能访问自己的已发布报告。
- 教师只能访问授权课程和班级的数据。
